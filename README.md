# TH_OOP_20252

## Giới thiệu

Đây là kho bài tập lập trình hướng đối tượng Java cho môn OOP (lớp TH_OOP_20252). Mỗi bài tập nằm trong thư mục `Lab`.


## Hướng dẫn chạy

1. Mở terminal ở thư mục dự án.
2. Biên dịch: `javac Lab**/*.java`
3. Chạy: `java Lab**.<TenLop>` (ví dụ `java Lab01.HelloWorld`)

## Ghi chú

- Yêu cầu Java JDK đã cài.
- Mục đích: học kỹ thuật cơ bản trong Java và thực hành OOP.
